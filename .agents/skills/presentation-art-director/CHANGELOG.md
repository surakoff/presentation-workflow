# История изменений

## 1.0.0 — первый стабильный релиз

- Единый процесс сборки презентаций по пользовательскому шаблону, с правилами для Figma, PPTX, PDF и анимации.
- Проверка шрифтов через Figma MCP до сборки. При недоступности шрифта сообщаем, что загрузить, и сохраняем исходное начертание.
- Локальный Auto Layout, проверка дерева слоёв и оптического выравнивания на рендере.
- Редактируемый PPTX, проверка исходного оформления, ссылок и встроенных шрифтов.
