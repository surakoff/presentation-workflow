# Инструменты и доступ

Подбирай инструменты по формату. Версии подключений и права на внешние файлы проверяй в текущем окружении.

| Маршрут | Что нужно |
| --- | --- |
| Figma Design | Подключение [Figma MCP в Codex](https://developers.figma.com/docs/figma-mcp-server/). Для записи нужны соответствующие инструменты и доступ на редактирование рабочего файла. Скиллы `figma-use` и `figma-create-new-file` используй там, где их предоставляет подключение. |
| Figma Motion | Для создания и проверки нативного таймлайна загрузи `figma-use-motion` вместе с `figma-use` из подключения Figma. Проверь доступность записи Motion API в текущем сеансе. Доступ к обычным слоям или чтению Motion сам по себе не подтверждает запись в таймлайн. |
| PPTX | Скилл `pptx` для работы с пакетом. Microsoft PowerPoint для проверки реальных рендеров, шрифтов, кликов и анимации. `ppt-master` нужен для подходящих сценариев реконструкции и анимации, а не для любого экспорта. |
| Оптимизация PDF | Figma Design для изменения слоёв. Скилл `pdf` применяй для просмотра и проверки самого PDF, когда файл экспортирован. |
| Видео | Установи Remotion для выбранного проекта и [официальные Remotion Skills](https://www.remotion.dev/docs/ai/skills). В проекте Remotion их можно добавить командой `npx remotion skills add`. |
| Pitchdeck | Используй при наличии плагина и нужной возможности в текущем аккаунте. Проверяй фактический результат экспорта в целевом формате. |

Для приложенных `pptx`, `pdf` и `ppt-master` начни с их собственных `SKILL.md`. Для PPT Master локальные зависимости указаны в `requirements.txt` внутри его папки. Установи их в отдельное Python-окружение только если выбран этот маршрут. Сторонние лицензии хранятся вместе с приложенными копиями.

Шрифты и шаблоны предоставляются для конкретной презентации. При отсутствии нужного начертания зафиксируй, какое именно нужно получить, и проверь влияние на результат. Для записей в Figma пользуйся своим подключением. Окружение, права доступа и подключение PowerPoint для автоматизации настраиваются индивидуально.
