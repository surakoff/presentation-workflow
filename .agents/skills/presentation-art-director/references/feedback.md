## Отправка

1. Регистрируй проблему по просьбе отправить отзыв. Из разговора возьми краткое название, ожидаемое и фактическое поведение, проект, дату и версию из метаданных установленной копии. Для неизвестного значения укажи «Не указано». Включи имя только если человек пожелал его оставить. Передавай только выбранные вложения и относящиеся к проблеме сведения.
2. Создай экземпляр мастера в секции новых. Размести его с отступом ниже существующих карточек, при необходимости увеличь секцию с сохранением её положения. Прочитай фактические ключи componentProperties. Дай номер из ID экземпляра: для ID вида A:B показывай № A-B, сохраняя обе группы цифр. Запиши «Обратная связь · № A-B» в поле «Номер обращения» и номер в имя узла. Заполни свойства «Название», «Описание», «Проект», «Версия скилла», «Дата обращения». Статус «Новое», решение скрыто; цвета наследуются от секции. Сохрани ID сразу. После сбоя повторно прочитай созданный узел перед повтором записи, чтобы не создавать дубль.
3. При получении байтов изображения вставь настоящий IMAGE fill в область «Скриншот», скрой заполнитель, сохрани пропорции и читаемость. Для нескольких изображений можно подготовить одну разборчивую композицию либо дополнительные фреймы вложений под карточкой с её номером. Переноси связанные фреймы вместе с карточкой. При отсутствии изображения скрой блок вложений. Проверь исходные байты или хеш загруженного изображения, реальные заливки, принадлежность к секции, поля и рендер перед подтверждением. Если была передана лишь часть вложений, перечисли недостающие.
4. Ответ отправителю: «Обращение № A-B отправлено. Чтобы узнать, как оно продвигается, напишите “Статус обращения”». При недоставленном изображении явно сообщи об этом. При неудаче записи сообщи о сбое и дай Telegram для связи.

## Проверка статуса

Распознавай также «Что там с обращением?», «Решили проблему?» и аналогичные вопросы по контексту. Возьми номер из запроса или последнего однозначно относящегося к вопросу подтверждения отправки в этом чате. При нескольких возможных номерах или в новом чате уточни номер. Не перечисляй карточки других пользователей. Каждый раз прочитай узел по обратному преобразованию A-B → A:B. Проверь файл, принадлежность к одной из двух секций, тип карточки и номер. Сравни секцию, статус и текст решения. Ответ о решении требует секции решённых, отметки «Решено» и содержательного описания.

- Новое: «Обращение № A-B пока открыто. Если есть вопросы, можно написать [автору скилла в Telegram](https://t.me/surakoff)».
- Решено: «Обращение № A-B решено. [Краткое содержание поля “Как решено”.] Если проблема осталась или есть вопросы, напишите [автору скилла в Telegram](https://t.me/surakoff)».
- При противоречии полей, отсутствующем решении или недоступности карточки укажи ровно то, что удалось подтвердить, и тот же контакт. Жалоба на неверное решение сама по себе не закрывает и не переоткрывает обращение.

## Разбор автором скилла

В контексте уполномоченного владельца по его запросу прочитай секции и выдай сводку по номерам либо реальный скриншот выбранной карточки. Для закрытия по поручению владельца запиши конкретное исправление и результат проверки, включи поле «Показать решение», задай статус «Решено» и перемести тот же экземпляр в секцию решённых. Цвет унаследуется от секции. Сохрани номер, описание и вложения. Перечитай карточку и осмотри рендер. Обычный запрос отправителя о статусе выполняй только на чтение.
