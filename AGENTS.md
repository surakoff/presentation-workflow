# Работа с презентациями

Для задач по презентациям применяй [presentation-art-director](.agents/skills/presentation-art-director/SKILL.md). Руководства внутри скилла одинаково применимы к работе в Codex и вручную.

Используй шаблон и шрифты, указанные для конкретной работы. Для записи в Figma используй согласованную рабочую область. Храни рабочие материалы в `projects/`, экспорт в `output/`. Для проверки пользуйся реальными рендерами из целевого инструмента и фиксируй, что было проверено.

Оптимизация для PDF и анимация выполняются по запросу. Для оптимизации прочитай руководство целиком и проверь каждый блок до выдачи. При обновлении общего правила меняй его в соответствующем руководстве.

При каждом изменении правил или поведения скилла увеличивай третье число версии в `metadata.version` в его `SKILL.md`. Добавляй краткую запись новой версии в начало [истории изменений](.agents/skills/presentation-art-director/CHANGELOG.md). Вместе с публикацией изменений выпускай на GitHub стабильный релиз с тегом `vX.Y.Z`, той же короткой записью и отдельным ZIP скилла из этого тега. Проверяй, что тег, версия в архиве и запись в истории совпадают. При обновлении установленного скилла показывай изменения с предыдущей версии.
